# NYC School Bus Delays and Breakdowns

Analysis of 282,191 reported school bus incidents across New York City: what causes delays and breakdowns, which operators and boroughs are worst affected, and how the pattern moves through the week.

**Tools:** Excel (pivot tables, charts, data cleaning)
